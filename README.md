# Department of Computing Website

A simple four-page HTML/CSS website created for the SWD 414 assignment.

## Pages
- `index.html` — Homepage
- `about.html` — About Us
- `programmes.html` — Available Programmes
- `contact.html` — Contact Us
- `style.css` — Shared styling

## Run the website
Open `index.html` in a web browser. No server or additional software is required.

## Important
Replace sample programme and contact information with accurate details from your institution before submission.
